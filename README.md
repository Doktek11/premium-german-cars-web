# Premium German Cars Web

Web corporativa de **Premium German Cars** desarrollada con **React + Vite + TypeScript + TailwindCSS**.

---

## Stack técnico

- React 18
- React Router DOM 6
- Vite 5
- TypeScript 5
- TailwindCSS
- react-helmet-async (SEO dinámico por página)
- @vercel/analytics

---

## Requisitos

- Node.js 18+ (recomendado)
- npm 9+

---

## Instalación

```bash
npm install
